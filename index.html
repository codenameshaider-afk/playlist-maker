How do I get a file list?

First try Choose music folder and pick the folder above. Some phone browsers only let you pick single files; if the count looks wrong, use a list file instead. On your Zorin PC, with the phone's SD card or folder copied or mounted, run this in a terminal (change the first path), then send the .txt to your phone:

cd "/path/to/That One Year(s)" && find . -type f \( -iname '*.opus' -o -iname '*.mp3' -o -iname '*.m4a' -o -iname '*.flac' \) | sort > ~/music-list.txt

Choose files works for one folder only: it can't see subfolders, so every file is assumed to sit directly in the music folder.
